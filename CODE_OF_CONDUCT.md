# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
contributors and maintainers make participation a harassment-free experience for everyone, and
the maintainers may remove, edit or reject contributions that do not.

Report unacceptable behaviour privately to the maintainers at dev@bubo2.com. Every report is
reviewed and kept confidential.
